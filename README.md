# MỘC MÌ – Website giới thiệu thương hiệu

## Chạy trên máy tính
1. Cài Node.js bản LTS.
2. Giải nén thư mục dự án.
3. Mở Terminal/CMD tại thư mục `moc-mi-website`.
4. Chạy `npm install`.
5. Chạy `npm run dev`.
6. Mở địa chỉ local mà Vite hiển thị (thường là http://localhost:5173).

## Đưa website lên mạng
Có thể triển khai miễn phí bằng Vercel hoặc Netlify: tải thư mục dự án lên GitHub, kết nối repository với Vercel/Netlify, build command `npm run build`, output directory `dist`.

## Nội dung
- React + Vite, responsive cho máy tính và điện thoại.
- Ảnh sản phẩm và logo sử dụng ảnh người dùng đã cung cấp.
- Video nhúng Google Drive, có liên kết dự phòng.
- Liên kết Google Maps, chỉ đường và nút gọi điện.
- Chưa có giỏ hàng, thanh toán, đăng nhập hoặc đánh giá khách hàng.

Lưu ý: Video Google Drive cần quyền chia sẻ phù hợp (bất kỳ ai có liên kết đều có thể xem) để iframe phát được. Kiểm tra lại số điện thoại và vị trí bản đồ trước khi công bố rộng rãi.
